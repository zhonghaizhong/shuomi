# POD butterfly / peony print showcase

This folder contains four full-size (1254 × 1254, transparent background)
high-quality WebP exports of the actual previously generated PNG artwork.

- `butterfly-peony-original.webp`: original source, displayed only in **My Assets**.
- `butterfly-peony-monochrome.webp`: fission design A, **Pending Review**.
- `butterfly-peony-warm.webp`: fission design B, **Pending Review**.
- `butterfly-peony-cluster.webp`: fission design C, **Pending Review**.

These files are checked in with Git and do not depend on browser session storage.
`manifest.json` records immutable IDs, SHA-256 hashes, and origin relationships.

**Important:** These are 1254-pixel, quality-95 WebP exports, not the original PNG
byte streams. Original high-resolution PNG sources were kept separately.
Before a production printer requires a particular lossless PNG, attach and
archive the verified original PNG as a distinct immutable source version.

The review UI uses the checked-in files and may store demo review decisions
locally per browser; it does not write official approval results to a shared backend.
No garment mockups or subsequent six-image product details were generated.
